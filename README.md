# Shetach Batuach — שטח בטוח

Public website, support and legal information for the riding conditions app **שטח בטוח**.

[Open the app](https://trail-status-il.ithamarcohen2209.chatgpt.site) · [Privacy policy](privacy.html) · [Support](support.html) · [Terms](terms.html)

The app shows regional weather observations and forecasts, official updates, rider hazard reports with optional location and photos, saved areas, and ride reminders. Registered users can manage profiles and submit reports. Authorized managers have a separate, server protected dashboard for moderation and notices. The currently deployed Web version is 2026.09.25-6.

Android and iPhone wrappers use the live hosted app. Native ride push delivery needs the service owner to configure Firebase and Apple server credentials; local reminders are available in installed builds. The public website is informational and does not provide an APK or iPhone installation package.

Application and wrapper source is maintained in the private `Shetach-Batuach-App` repository. This public repository contains only website, support and legal material.
